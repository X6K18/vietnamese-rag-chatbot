# Dataset Directory Structure

This folder contains the data used for the PHO_BERTS project, organized into raw and processed stages.

## Directory Layout

```text
data/
├── processed/      # Cleaned and pre-processed data ready for model training
└── raw/            # Original, unedited source documents categorized by topic
    ├── du_lich/    (Travel)
    ├── kinh_te/    (Economics)
    ├── phap_luat/  (Law)
    ├── tam_su/     (Confessions/Personal stories)
    ├── the_gioi/   (World news)
    ├── the_thao/   (Sports)
    ├── thi_truong/ (Market news)
    ├── thoi_su/    (Current affairs)
    ├── truyen_hinh/ (Television/Media)
    ├── van_hoa/    (Culture)
    ├── xa_hoi/     (Society)
    ├── y_kien/     (Opinions)
    └── y_te/       (Health/Medical)
